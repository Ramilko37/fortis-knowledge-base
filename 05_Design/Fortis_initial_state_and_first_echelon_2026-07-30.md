# Fortis `/prototype`: начальное состояние и первый эшелон — 2026-07-30

## Контекст

Входящая спецификация `Fortis_initial_state_and_first_echelon_spec.md` задаёт контракт первого запуска `/prototype` без `projectId` и без demo-режима.

## Решение

`/prototype` по умолчанию открывает новый чистый проект:

- название: `Новый проект защиты`;
- версия: `v1`;
- стоимость: `0`;
- бюджет не задан;
- нет защитных эшелонов и размещённых объектов;
- нет демо-слоёв L1-L10, критических зон, маршрутов угроз и статических demo-overlays;
- системный `L0 · Зона предприятия` отображается от `DefenseProject.baseObject`, но не является эшелоном защиты, не влияет на стоимость, аудит, покрытие и отчёт;
- локальный незавершённый проект не восстанавливается автоматически, а предлагается отдельным уведомлением `Продолжить / Не сейчас`;
- backend test variant не создаётся автоматически.

Первый пользовательский flow начинается с onboarding:

- основной CTA: `Создать первый эшелон защиты`;
- мастер создаёт L1 `Обнаружение`;
- рекомендованная геометрия — круг вокруг объекта защиты;
- после создания L1 становится активным эшелоном, инспектор остаётся закрытым;
- библиотека средств открывается только по явному действию, рекомендации сортируются наверх детерминированно;
- размещение начинается только через явное действие `Разместить`;
- drag/drop из библиотеки ставит средство в точку отпускания курсора на карте; slot/шаблонные позиции в `/prototype` не используются и не показываются;
- во время drag пользователь тянет компактную иконку средства, а не всю карточку библиотеки;
- после клика по карте создаётся `PlacedDefenseObject`, выбирается размещённый объект, открывается инспектор и обновляется стоимость.
- карточка настройки МОГ открывается сразу при установке МОГ на карту и при выборе уже размещённого МОГ; она оформляется в новом дизайне `/prototype`, без generic drawer-панели.

`Аудит`, `Сравнение` и `Отчёт` в начальном сценарии недоступны до появления данных, необходимых для расчёта. Старые статические demo-значения вроде `73%` и `+21,5 млн ₽` не должны появляться в default `/prototype`.

## Последствия

- Demo-данные остаются только за явным demo/preset-сценарием.
- Empty state считается полноценным рабочим состоянием, а не предварительно заполненной демо-конфигурацией.
- Рекомендации библиотеки должны быть детерминированной функцией текущего эшелона и каталога, без скрытого auto-select или auto-placement.
