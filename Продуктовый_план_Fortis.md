# Обновлённый продуктовый план Fortis

**Дата актуализации:** 2026-06-09

## Коротко

Fortis — это конструктор защиты объекта. Типовой путь пользователя:

- карта → эшелоны → средства → размещение → объекты → покрытие → конфликты → расчёт → отчёт

`/calculate/` не рассматриваем как критический путь продукта. Основной маршрут расчёта — `/calculator/`.

## Текущий фокус

Главный ближайший milestone:

- Любое размещение на карте должно становиться объектом `PlacedDefenseObject` в `DefenseProject`.
- Изменение объекта должно сразу отражаться во всех местах:
  - на карте
  - в списке объектов эшелона
  - в калькуляторе
  - в печатном отчёте

Единый источник правды для пользовательской конфигурации:

- `DefenseProject.layers`
- `DefenseProject.placedObjects`
- `DefenseProject.assetLibrary`

`useDefenseStudioStore` остаётся для 3D/demo-runtime-слоёв, но **не** используется как основная модель расчётных размещений.

## Assumptions

- `/calculator/` — основной маршрут расчёта.
- `/calculate/` не нужен как алиас (бывшая ошибка маршрутизации).
- Backend не входит в ближайший scope; демо-контур остаётся frontend-only.
- Средства библиотеки по-прежнему размещаются как условные объекты эшелона, включая OSINT/штабы/организационные сущности.
